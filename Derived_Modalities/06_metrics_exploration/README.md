# 06_metrics_exploration

A place to try new metrics for comparing domain maps beyond ARI/NMI, for example:

- spatial continuity of domains,
- domain enrichment for a readout,
- consistency across samples,
- which features define each domain in each modality.

Each metric gets one notebook or script with a short note: what it measures and when it fails. Metrics that prove useful move to `05_evaluation/`.
